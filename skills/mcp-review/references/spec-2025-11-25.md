# The handshake era: 2025-11-25

2025-11-25 is the last revision built on an `initialize` handshake, and the one
Alexa+ add-ons speak today. A dual-version server still serves it; reviewing
with `--target 2025-11-25` checks a server for this era only and skips the
modern-only rules.

## How a 2025-11-25 session works

1. The client sends `initialize` with `protocolVersion`, `capabilities`,
   `clientInfo`; the server answers with the version it agrees to, its
   capabilities and `serverInfo`.
2. The client sends `notifications/initialized`.
3. On Streamable HTTP the server may mint `Mcp-Session-Id`; the client echoes
   it, and the `MCP-Protocol-Version` header (since 2025-06-18) on every
   request after initialization. DELETE ends the session.
4. The client may open a GET stream for server-initiated messages; the server
   may send *requests* (sampling, elicitation, roots) on SSE streams; streams
   are resumable with `Last-Event-ID`.

## What 2025-11-25 added (changelog against 2025-06-18)

- OpenID Connect Discovery for authorization server discovery (PR #797).
- Icons on tools, resources, resource templates and prompts (SEP-973).
- Incremental scope consent via `WWW-Authenticate` (SEP-835).
- Tool name guidance (SEP-986) — the basis of `MCP064`.
- Elicitation enums standardised (SEP-1330) and URL-mode elicitation
  (SEP-1036) — URL mode's `-32042` and `notifications/elicitation/complete`
  are gone again in 2026-07-28.
- Tool calling in sampling (`tools`, `toolChoice`, SEP-1577).
- **Client ID Metadata Documents** as a recommended registration mechanism
  (SEP-991) — DCR becomes Deprecated a revision later.
- **Experimental tasks** (SEP-1686) — moved to an extension in 2026-07-28
  (`MCP090`).
- Minor: stdio servers may log anything to stderr; 403 for invalid `Origin`;
  input validation errors returned as tool execution errors (SEP-1303) so the
  model can correct itself; SSE polling (SEP-1699); PRM discovery aligned with
  RFC 9728, `WWW-Authenticate` optional with a `.well-known` fallback
  (SEP-985); JSON Schema 2020-12 as the default dialect (SEP-1613).

## Error codes of this era

`-32002` resource not found and `-32042` URL elicitation required are legal
here and forbidden in 2026-07-28 (`MCP050`, `MCP052`), and clients SHOULD
still accept -32002 from older servers. Hand-written not-found errors therefore
use -32602 on the modern path; the Python v2 SDK already reports a missing
resource as -32602 with the `uri` in `data` (its migration guide).

## What reviewing at `--target 2025-11-25` still reports

SDK mismatches (MCP003-006), deprecated features (they were not yet
deprecated, but the review states the 2026-07-28 status for planning), tool
hygiene (MCP06x), stdio stdout writes (MCP080), HTTP+SSE (MCP082), MCP Apps
resources (MCP091). It does not report sessions, a missing `server/discover`,
header validation, `resultType`, cache hints, removed methods or the
2026-07-28 error-code rules.

## Older revisions

2025-06-18 introduced the `MCP-Protocol-Version` header; servers that support
clients older than that MAY treat a request without it as 2025-03-26. The
HTTP+SSE transport of 2024-11-05 has been deprecated since 2025-03-26.
